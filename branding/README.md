# MangaFocus branding assets

This directory stores source branding files used to prepare distribution and
listing artwork. These files are development assets and are intentionally
excluded from the installable plugin ZIP.

## Directories

- `source/`: received source files, preserved without conversion.
- `source/screenshots/`: finalized WordPress.org screenshots, stored with their
  lowercase public filenames.
- `../.wordpress-org/`: WordPress.org plugin-directory asset candidates.

The current design candidate uses monochrome manga artwork with blue accents.
When an asset is revised, keep the WordPress.org filename stable and preserve
the supplied source file here when its format or compression differs.
