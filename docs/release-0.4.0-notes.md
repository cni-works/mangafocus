# MangaFocus Free 0.4.0 リリースノート案

WordPress.org公開前の正式成果物準備。今回GitHub・SVNへは公開しない。
ユーザーより最新候補ZIPのWordPressテスト環境での動作確認完了との報告を受領。正式版の実装はその候補と一致させ、バージョン・配布説明・カタログ版情報だけ変更する。

= 0.4.0 =

* 通常表示・全画面表示・コマ読みを個別に選択可能に。旧設定と保存値を保持。
* 設定画面とコマ読み開始位置の選択肢を整理。1ページ表示では見開き専用設定を非表示。
* ブロック設定に表紙画像を追加。アイキャッチの自動設定を廃止し、既存表紙を維持。
* 縦長表紙の左右余白と、画像を覆わない案内矢印の配置を改善。
* 自由ズームOFF時の縦読みと、中間ページからの開始位置を修正。
* 小画面の全画面ページ送り配置と日本語の設定説明を改善。

## 更新時の注意

既存の漫画・設定・表紙を保持します。表示モードを変更するまでは旧設定を維持します。1ページ目からのアイキャッチ自動設定は行いません。

通常表示は投稿内で読むモード、全画面表示はページ送りまたは縦読み、コマ読みは設定した領域を順に拡大する機能。「専用ビュアー」という新しい独立モードは追加していない。
表紙UIは標準featured_media／_thumbnail_idと共通。標準アイキャッチパネルを維持。自動アイキャッチの書き込みは廃止したまま、未設定時の1ページ目代替表示を維持。
コマ読みステップ・スマホコマのフォールバック・保存スキーマ・ライブラリ標準プレビューの新実装は今回行わない。
