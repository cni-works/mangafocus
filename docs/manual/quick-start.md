# 5分クイックスタート

この手順では、投稿または固定ページへ漫画を直接配置します。

## 1. ブロックを追加する

投稿または固定ページのブロックエディターを開き、ブロック追加から「AI Manga Viewer」を選びます。「登録済みViewer」ではなく「AI Manga Viewer」を選択してください。

## 2. ページ画像を選ぶ

ブロック設定の「ページ画像」で「ページ画像を選択」を押し、漫画画像を読む順に複数選択します。

- 先頭画像は「表紙」として扱われます。
- 最後の画像は一覧で「巻末」と表示されます。
- 画像はドラッグ、または上下の矢印で並べ替えられます。
- 不要な画像はゴミ箱ボタンで削除できます。

## 3. ページの読み方を選ぶ

「ページ送り」パネルの「ページレイアウト」を設定します。

- **1ページ**：1枚ずつ表示します。迷った場合はこれを選びます。
- **見開き**：組み合わせ可能な縦長画像を2枚並べます。
- **自動**：Viewerの表示幅が広いときは見開き、狭いときは1ページへ切り替えます。

漫画では通常「右綴じ（漫画向け）」を使用します。左から右へ読む冊子などは「左綴じ」を選びます。

## 4. 読者向けの操作を選ぶ

必要に応じて次を設定します。

- 「ページ番号を表示」
- 「ページ端クリックで送る」
- 「案内矢印をすべてのページで表示」
- 「ページめくり演出」
- 「全画面ボタンを表示」
- 「自由ズームと移動を有効化」

スマートフォンで文字が小さくなる漫画では、全画面または自由ズームを有効にして公開画面を確認してください。

## 5. プレビューして公開する

投稿を保存し、公開画面で次を確認します。

1. 画像の順番
2. 前後のページ送り
3. 右綴じ／左綴じの方向
4. ページ番号
5. PCとスマートフォンの表示
6. 有効にした場合は全画面とズーム

キャッシュ系プラグインを使用している場合、変更が見えなければキャッシュ削除またはスーパーリロード後に確認します。
