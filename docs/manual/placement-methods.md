# 漫画を作成・配置する4つの方法

MangaFocusには、漫画を作る場所と公開ページへ置く方法が複数あります。最初に用途を決めると迷いにくくなります。

## 違いの一覧

| 方法 | 何をするものか | 適する用途 |
| --- | --- | --- |
| Direct Viewer | 投稿や固定ページ内で漫画を直接作る | まず試す、1か所だけに掲載する |
| Manga Library | 漫画を独立した作品として登録・管理する | 複数箇所で再利用する、解析する |
| 登録済みViewer | Libraryの作品をGutenbergで選んで表示する | ブロックエディターで再利用する |
| ショートコード | Viewer IDを使ってLibrary作品を表示する | Classic Editor、ページビルダー、ショートコード対応欄 |

## Direct Viewer

「MangaFocus」ブロックを投稿や固定ページへ追加し、その場で画像や表示方法を編集します。すぐに作り始められるため、最初の動作確認に適しています。

Direct Viewerは配置した投稿の中に設定を保存します。同じ漫画を別の投稿へ再利用したい場合は、Manga Libraryへ登録します。

## Manga Library

WordPress管理画面の「漫画ライブラリ」で作品を管理します。登録済み漫画の一覧には、表紙、タイトル、公開状態、ページ数、Viewer ID、更新日時が表示されます。

一覧から次の操作ができます。漫画解析とAI相談の操作は、対応するPro機能が利用可能な場合に表示されます。

- 編集
- 解析を見る【Pro】
- AI相談資料を作成【Pro】
- ショートコードをコピー
- クイック編集、ゴミ箱、一括操作などのWordPress標準操作

解析がOFFの場合は「解析停止中」と表示され、管理権限がある利用者には「解析を有効にする」が表示されます。

### Direct ViewerをLibraryへ登録する

Direct Viewerの「漫画ライブラリに登録」パネルでタイトルを入力し、「漫画ライブラリに登録」を押します。現在のページ、Viewer設定、保存済みの互換設定を使って独立した漫画が作成されます。

重要：登録後のDirect ViewerとManga Library作品は自動同期されません。一方を編集しても、もう一方へ自動反映されないため、今後どちらを正本として使うか決めてください。

登録後は次の操作が表示されます。

- 「登録した漫画を編集」
- 「ショートコードをコピー」
- 「このブロックを登録済みViewerへ切り替える」

公開権限がない場合は下書きとして登録されます。Library作品を公開した後に登録済みViewerへ切り替えられます。

## 登録済みViewer

投稿や固定ページへ「登録済みViewer」ブロックを追加します。表紙カードから作品を選び、必要なら「タイトルまたはViewer IDで検索」を使用します。

編集画面には選択した表紙だけが表示され、公開画面ではViewer全体が表示されます。作品内容を変更する場合は、投稿側ではなくManga Libraryの作品を編集します。

「漫画ライブラリから選び直す」で別作品へ変更でき、「選択を解除」で未選択状態へ戻せます。

## ショートコード

Manga Library一覧で表示されるコードをクリックするとコピーできます。

```text
[ai_manga_viewer id="123"]
```

`123`は作品ごとのViewer IDです。Classic Editor、ショートコードブロック、ショートコード実行に対応したページビルダーなどへ貼り付けます。

Library作品が下書きや非公開の場合、編集権限を持たない一般読者には表示されません。ショートコードが文字のまま表示される場合は、貼り付け先がWordPressショートコードの実行に対応しているか確認してください。

## 解析対象になる配置【Pro】

現在の漫画解析はManga Library登録済み作品を対象とします。「登録済みViewer」ブロックまたはショートコードで表示したLibrary作品を使用してください。投稿内のDirect Viewerは解析対象になりません。
