# 読み方と表示設定

読み方は、次の4段階に分けて考えると整理しやすくなります。

## 1. ページ内へどう置くか

「ページ内の表示」パネルの「表示方法」で選択します。

### ページ内でそのまま読む

投稿内にViewer全体を表示します。そのままページ送りでき、設定されていれば「全画面で読む」を使用できます。Proのコマ読みを設定した環境では「専用ビューアーで読む」も表示されます。

### 表紙から全画面で読む

投稿内には表紙と「漫画を読む」ボタンを表示します。読者がボタンを押すと全画面で漫画が開きます。Proのコマ読みも設定されている場合は「専用ビューアーで読む」も表示されます。

長い投稿内でViewerの高さを抑えたい場合や、作品一覧から読ませたい場合に適しています。

## 2. 何ページ並べるか

「ページ送り」パネルの「ページレイアウト」で選択します。

### 1ページ

常に1枚ずつ表示します。画像の縦横比を問わず使いやすく、既存Viewerの基本設定です。

### 見開き

表示幅が十分なとき、組み合わせ可能な縦長ページを2枚並べます。狭すぎるViewerでは安全のため1ページへ戻る場合があります。

横長画像は、それ自体が見開き画像である可能性があるため単独表示されます。縦長ページの組がない場合は「見開き（利用できません）」と表示されます。

### 自動

Viewerの実際の幅を基準に1ページと見開きを切り替えます。PCでも狭いカラムでは1ページになり、スマートフォンでも基本的に1ページになります。

縦長ページをPCでは本のように、スマートフォンでは読みやすく1枚ずつ見せたい場合に適しています。

### 先頭ページを単独表示（表紙向け）

見開きまたは自動で、先頭画像だけを表紙として単独表示します。その後のページから見開きを作ります。

## 3. 全画面でどう読むか

「全画面ボタンを表示」を有効にすると、「全画面の読み方」を選べます。「表紙から全画面で読む」の場合も同じ設定を使用します。

### ページ送り

通常Viewerと同じようにページ単位または見開き単位で送ります。前後ボタン、ページ端、スワイプ、左右キーを利用できます。

### 縦スクロール

すべてのページを上から下へ並べ、スクロールして読みます。ページを送るより縦方向に続けて読みたい作品に適しています。

## 4. 見開きを全画面でどう見せるか

ページレイアウトが「見開き」または「自動」、全画面の読み方が「ページ送り」のとき、「全画面の見開き表示」を選べます。

### 見開き全体

2ページを同時に表示します。本を開いた状態に近い見え方です。

### 1ページずつ大きく読む

見開きの構造を保ちながら、全画面では片方のページへ順番に注目します。通常のページ内Viewerでは見開き全体を表示します。

これはコマ読みとは別の機能です。ページ全体を1枚ずつ大きく見せる機能で、コマ枠は使用しません。

## 補助設定

### 綴じ方向

- **右綴じ（漫画向け）**：一般的な日本の漫画向け。
- **左綴じ**：左から右へ読む冊子などに使用。

### 自由ズームと移動

読者が＋／－、ピンチ操作で拡大できます。拡大中は画像をドラッグして移動できます。ズームボタンは「下（横並び）」「右（縦並び）」「左（縦並び）」から選択できます。

### スクロール位置を整える

ページを切り替えたときに漫画が読みやすい位置へ寄る補助です。「合わせる位置」と「引っかかりの強さ」を調整できます。テーマや固定ヘッダーによって見え方が変わるため、公開画面で確認してください。

## 迷った場合の推奨

| 作品 | 推奨設定 |
| --- | --- |
| 横長の広告漫画 | 1ページ + 全画面 + 自由ズーム |
| 縦長の一般的な漫画 | 自動 + 先頭ページ単独 + 全画面 |
| スマートフォン中心の縦読み作品 | 1ページ + 全画面の縦スクロール |
| 投稿内をコンパクトにしたい | 表紙から全画面で読む |
| PCで文字を大きく見せたい縦長漫画 | 自動 + 全画面の「1ページずつ大きく読む」 |

設定後はPC、スマートフォン、画面回転、狭いカラムで確認してください。
