# Phase 5 CTA基盤の検証記録

2026-09-27 / 0.2.0-alpha / 作業ブランチ: feature/cta-foundation

## 最小実装

- 各ページの`pages[].cta`へ任意のCTA設定を保持する。既存ページにCTAがない場合の表示・保存互換を維持する。
- CTAはページごとにON/OFFでき、文字ボタンまたはメディアライブラリの画像を選択する。新しくCTAを設定するページでは画像上の自由配置を既定ONとし、保存済みCTAの配置設定は変更しない。
- リンク先URL、新しいタブ、下部の左・中央・右を設定できる。自由配置をONにすると、画像上のドラッグまたは数値設定で位置・幅を指定できる。最終ページを基本用途とするが、任意ページへ設定できる。
- 自由配置の文字ボタンは、文字サイズ、文字色、背景色、枠色、角丸をページごとに指定できる。自由配置情報がない既存CTAは従来の下部配置として表示する。
- CTAごとに、一定間隔で光る注目アニメーションと、マウスオーバー時の「少し浮く」「少し暗くなる」を選択できる。既定は演出なしとし、動きを減らすOS設定では光る演出と浮き上がりを停止する。
- 公開側は通常表示、全画面表示、専用コマビューアーへページ内オーバーレイとして表示する。ページ・コマ送り時は対象ページと一緒に切り替わる。
- CTAは拡大中もページ面の一部として表示し、画像と一緒に拡大・移動する。CTA上のタップはリンク操作、周囲のドラッグはパン操作として扱う。
- 専用コマビューアーでは、表示中のページ画像と同じ座標・大きさのCTAレイヤーを重ねる。コマの拡大位置に追従し、CTAがあるページだけ表示する。クリック計測は専用ビューアー内の操作として記録する。
- 文字、URL、画像ID・URL・代替テキスト、位置・サイズ・色をPHP側でサニタイズし、数値を許容範囲へ制限する。リンク先や表示内容が不足したCTAは出力しない。別タブでは`noopener noreferrer`を付ける。
- 直接配置したViewerとManga Libraryから参照したViewerは同じページデータ・描画処理を使う。

## 今回含めないもの

- 複数CTA、自由な説明文や背景を持つCTA専用ページ
- CTAテンプレート、自動見切れ補正

## ローカル検査

- PHP構文、文字・画像CTAの出力、URL検証、文字エスケープ、別タブ属性を確認する。
- JavaScript構文と既存ブロックスキーマ互換を確認する。
- Edgeの幅1200px、390px、320pxでCTAがViewer内へ収まり、全画面でも表示されることを確認する。
- ズーム中もCTAが表示され、画像と同じ変形を受け、CTAのクリックと周囲のパンを区別できることを確認する。
- 専用コマビューアーでCTAがコマ拡大後の画像位置へ追従し、リンク操作と専用ビューアー内CTAクリック計測が1回だけ行われることを確認する。
- RTL/LTRページ送り、ズーム、全画面、専用ビューアー、CNI Blocks共存の回帰検査を継続する。

## WordPress実機で確認する項目

1. 任意ページでCTAをONにし、文字、URL、下部配置／自由配置、別タブ設定を保存・再読込できる。
2. CTA画像を選択・変更・削除し、代替テキストとリンクが公開画面へ反映される。
3. 最終ページ以外を含む複数ページへCTAを設定し、対象ページだけに表示される。
4. 自由配置CTAを画像上でドラッグし、位置・幅・文字サイズ・色・角丸が通常表示と全画面表示へ反映される。
5. CTA上のクリックがページ端送りへ奪われず、指定URLへ一度だけ移動する。
6. ズーム中もCTAが画像と一緒に拡大・移動し、CTAはタップできる。周囲のパン・三角送りと競合しない。
7. Manga Libraryの登録済みViewerをショートコードと参照ブロックで表示し、CTA更新が両方へ反映される。
8. CTA未設定の既存投稿に表示差分や保存データの欠落がない。
9. 専用コマビューアーで、CTA設定ページの各コマにCTAが表示され、ページが変わると対象ページのCTAへ切り替わる。CTAへTab移動でき、クリックがコマ送りへ奪われない。

実機確認後、CTA専用ページを追加するかを決める。

## 実機確認から追加したCTA方針

- 下部・左／中央／右に加え、ページ画像上の任意位置へCTAを置き、ドラッグ移動とサイズ調整を行う方式をローカル実装した。
- 文字、リンク、文字色、背景色、枠色、ボタン幅、文字サイズ、角丸を最初の調整対象とした。既存のCTAデータは維持し、自由座標がない既存CTAは現在の下部配置として表示する。
- CTAは任意ページへ設定できる方針を維持する。複数ボタンや自由な説明文まで扱う「CTA専用ページ」は、画像ページとは異なるレイアウトデータが必要になるため別段階とする。最初の自由配置CTAへ同時に詰め込まない。
- 専用コマビューアー内でも現在ページのCTAを表示し、既存Analyticsへ専用ビューアー内クリックとして送信する。
