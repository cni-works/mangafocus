# 安定化・実機検証の記録

2026-09-26 / 0.1.0-alpha / 作業ブランチ: feature/viewer-navigation-stability

## 今回の修正

通常ページとコマ読みの操作方向を綴じ設定に合わせた。右綴じは左キー・右向きスワイプで次へ、左綴じは右キー・左向きスワイプで次へ進む。戻る操作はその逆。コマ読みの端ボタンは「次」が右綴じで左側、左綴じで右側になり、前／次のラベルと実際の動作を一致させた。

通常表示と専用ビューアーのページ送り演出も綴じ方向に合わせた。右綴じで進む場合はページの左側を持って右方向へ、左綴じで進む場合は右側を持って左方向へめくる。戻る動作はその逆とする。回転だけでは方向が曖昧に見えるため10%の横移動を加え、従来の約90度まで横につぶれて強く暗転する動きも、72度・弱い暗転へ抑えた。

スワイプは1指・横方向が主体・所定距離以上の操作だけを対象とする。縦方向主体、複数指、touchcancel、短い動きでは送らない。通常ページとコマ読みで同じ判定を使う。これは自由ズーム機能の追加ではない。

ページ番号は画像上の絶対配置から通常のレイアウトへ移し、専用ビューアーボタンの上に独立した行で表示する。ページ番号とボタンが同じ下端位置を使って重なる問題を解消した。幅1200px、390px、320pxで両要素の境界が重ならず、ボタンが表示領域内に収まることをブラウザー検査で確認した。

専用ビューアーの開始位置に「現在のページから開始」を追加した。既定のOFFでは、通常表示で2ページ目以降を開いていても先頭から開始する。ONでは、現在のページに対応する最初のコマ（コマ未設定ならページ全体）から開始する。既存投稿は属性が未保存でもOFFとして扱い、従来の開始動作を維持する。両方の動作をPC・スマホ幅で確認した。

保存属性に `focusReaderStartAtCurrent`（既定値false）を追加した。PHP描画は開始位置を `data-focus-start` として出力する。ブロック名とVersionは変更していない。CNI Blocks側の変更、サイトへの反映、commit/pushは行っていない。以前のロードマップ編集は未コミットのまま保持している。

## ローカル検査

- PHP本体・描画ファイルの構文検査、エディター・フロントJSの構文検査: 合格。
- render-smoke.php: 登録、空データ、出力エスケープ、旧新描画の共存・一致に合格。
- browser-smoke.cjs: EdgeでPC/スマホ幅の共存、独立操作、コマ数、フォーカス循環・復帰に合格。左右綴じごとの通常ページ／コマ読みのキー・スワイプ、端ボタンの位置と前後移動、縦方向・複数指・キャンセル・短距離操作の回帰検査を追加し合格。
- browser-smoke.cjs: 右綴じ・左綴じについて、通常表示と専用ビューアーの進む／戻る演出が対応する回転方向を使用することを確認し合格。
- browser-smoke.cjs: ページ番号と専用ビューアーボタンの位置関係を1200px、390px、320pxで確認し、重なりなし・画面外へのはみ出しなしに合格。
- browser-smoke.cjs: 通常表示を2ページ目にした状態から、開始位置が既定OFFなら先頭、ONなら現在ページに対応するコマで専用ビューアーが開くことを確認し合格。
- 追加テストの最初の実行は模擬画像の取得待ちでタイムアウト。既存テストと同じローカル画像応答を設定した再実行で合格。
- release-smoke.ps1: 同版上書き防止、不正入力、失敗時の既存ZIP保持、Force置換、内容一覧の検査に合格。

タッチ検査は合成TouchEventであり、物理スマホのスクロール・ジェスチャー検証を代替しない。WordPress実機とPHP 7.4での実行は未確認。Phase 1.5〜2全体の完了とはしない。
